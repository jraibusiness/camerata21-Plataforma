Skills de Design e Front-End (Interface Profissional)Estas skills garantem que o Claude Code não crie sites com aquela estética genérica de inteligência artificial ("AI slop"), focando em UI/UX moderna e performance.frontend-design (Oficial da Anthropic): É a skill de front-end mais famosa do mundo, com mais de 277 mil instalações. Ela funciona como um diretor de arte, forçando o Claude a definir uma paleta de cores, tipografia e identidade visual estruturada antes de digitar qualquer linha de código. Está disponível no repositório oficial anthropics/skills.react-best-practices: Essencial se você estiver construindo aplicações modernas (com Next.js ou React). Ela dita regras estritas de componentização, uso correto de Server Components e otimização de estados para garantir que a aplicação não quebre em produção.landing-page-design: Focada em conversão, copy voltado para vendas e estruturas focadas em otimização de SEO e tráfego pago. Excelente para páginas institucionais e de produtos SaaS.theme-factory: Permite gerar esquemas visuais complexos e customizados e sistemas de design de forma consistente a partir de uma única instrução base.2. Skills de Estrutura e Engenharia de ProduçãoSites profissionais exigem planejamento, testes e segurança rígidos. Estas ferramentas ajudam o Claude Code a agir como um engenheiro de software sênior.obra/superpowers: Uma das queridinhas da comunidade com mais de 150 mil estrelas no GitHub. Ela obriga o Claude Code a desacelerar e planejar antes de programar. Ele cria casos de teste (Test-Driven Development) e mapeia vulnerabilidades antes de lançar o código final.GStack (de Garry Tan): Com quase 110 mil estrelas, essa coleção divide o Claude Code em funções específicas do seu time de desenvolvimento através de comandos rápidos /. Você pode alternar o Claude para o modo de "Designer", "Product Manager", "QA" (garantia de qualidade) ou "DevOps".Jeffallan/claude-skills: Um repositório de muito sucesso (10 mil estrelas) que agrupa 66 habilidades full-stack organizadas para a web. Destacam-se as sub-skills Architecture Designer (para planejar o banco de dados) e Fullstack Guardian (para implementar autenticações seguras).web-app-testing (Oficial da Anthropic): Com mais de 70 mil instalações, essa skill transforma o agente em um testador automatizado (usando frameworks como Playwright), abrindo um navegador virtual para testar cliques, formulários e fluxos do seu site e garantir que tudo funcione.3. Integrações Avançadas e APIs (MCP)mcp-builder: O padrão Model Context Protocol (MCP) conecta o Claude de forma segura a ferramentas de terceiros. Com essa skill, você pode fazer o Claude integrar o site que ele está construindo diretamente a provedores de pagamento como o Stripe, serviços de autenticação do Supabase ou envio de e-mails, gerando as conexões automaticamente.firecrawl: Permite que o Claude Code acesse URLs externas de forma otimizada com um sistema profissional de web scraping. É ideal para quando você quer fornecer um site de referência de mercado e pedir para o Claude extrair a estrutura técnica dele como inspiração.
