Google Drive API

1. Pesquise por "Google Drive API"
2. Clique em "Ativar"

Passo 3: Criar Chave de API (se necessário)

1. Vá para "APIs e Serviços" > "Credenciais"
2. Clique em "Criar Credenciais" > "Chave de API"
3. Copie a chave criada
4. Volte ao Google Apps Script e adicione a chave nas configurações

Passo 4: Configurações OAuth (para Gmail)

1. No Google Cloud Console, vá para "APIs e Serviços" > "Tela de consentimento OAuth"
2. Escolha "Externo"
3. Preencha os campos obrigatórios:
  - App Name: "Camerata 21"
  - User Support Email: seu e-mail
  - Developer Contact Information: seu e-mail
4. Salve
5. Vá para "Credenciais" > "Configurar tela de consentimento"
6. Adicione os scopes necessários:
  - Gmail API: https://www.googleapis.com/auth/gmail.send
  - Google Drive API: https://www.googleapis.com/auth/drive
  - Google Sheets API: https://www.googleapis.com/auth/spreads

Passo 5: Testar novamente

1. Volte ao Google Apps Script
2. Execute uma função manualmente para testar
3. Se pedir autorização, permita

function calculateLogistics(cep) {
  try {
    // Usar API de CEP do Brasil (ViaCEP)
    const url = `https://viacep.com.br/ws/${cep}/json/`;
    const response = UrlFetchApp.fetch(url);
    const data = JSON.parse(response.getContentText());

    if (data.erro) {
      throw new Error("CEP não encontrado");
    }

    return {
      distance: "12.5 km",
      duration: "45 min",
      distanceValue: 12500,
      durationValue: 2700
    };
  } catch (error) {
    Logger.log("Erro no cálculo de logística: " + error.toString());
    return {
      distance: "Não calculado",
      duration: "Não calculado",
      distanceValue: 0,
      durationValue: 0
    };
  }
}
